## Planning and authorization

Scope Plan proposes work; Publish requires approval of the concrete plan; Audit is read-only. Shape investigation supplies read-only engineering evidence. None replaces an Owner Grant or independent Shape validation.

## Routing and evidence

Assignees provide candidates. Nibfin is intended to inspect the current API array order and eligible Runners; GitHub matches labels and queues work. A qualified online but busy Runner retains the member’s priority. Labels are routing indexes, not identity or authorization proofs.

A Candidate binds source and required artifacts. Independent Acceptance, exact-head CI, final review, protected Merge and Closure evidence remain separate gates. See [Architecture](../architecture/).
