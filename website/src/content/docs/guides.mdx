## Planned guide areas

Future verified guides will cover approved Scope Plan/Publish/Audit, native dependency readback, Runner creation and registration, member-controlled removal, upgrades and safe recovery. This shell supplies no executable installation recipe or new CLI command.

## Collaboration boundary

Members retain their own Agent login and resources. Repository ownership does not determine Runner registration level. Optional automatic registration requires explicit Owner enablement and current eligibility; ordinary membership is not Runner administration permission.

When a provider write has an unknown result, inspect actual state before retrying. Do not bypass authorization, Acceptance or CI. See [Reference](../reference/) and [Troubleshooting](../troubleshooting/).
