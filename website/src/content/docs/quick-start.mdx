## Planned onboarding

A verified end-to-end Quick Start is not supplied by this shell. Consult the immutable release and compatibility evidence before installing Core, the Action or the CLI; no version is certified here.

The planned sequence is repository initialization, member Runner preparation, raw scope Issue creation, native dependency verification, and a separate Owner Grant before protected delivery. A raw Issue may be created manually. The optional official Scope Plan → user approval → Publish path does not grant delivery authority.

## Before execution

Confirm actual repository permissions, the current Assignee and Runner binding, applicable dependencies and Owner authorization. Never treat a public Issue, label or Runner registration as permission. See [Concepts](../concepts/) and [Troubleshooting](../troubleshooting/).
