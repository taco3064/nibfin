## Planned contract index

The official Scope Skill has Plan, Publish and Audit modes, not extra CLI commands. Future references will bind actual Core, Skills, Workflow, Action and CLI releases to immutable compatibility evidence.

## Compatibility status

No Agent/OS/architecture combination is certified by this website shell. Unverified means insufficient executed evidence; Unsupported means excluded or unable to satisfy required boundaries. Private repository product support is Unsupported. Personal and organization ownership of public repositories are in product scope.

Repository Runner registration, organization-level registration and optional automatic registration require distinct permission and configuration checks. A CLI installation result does not prove full product delivery. See [Quick Start](../quick-start/).
