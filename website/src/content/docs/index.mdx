Nibfin is being developed to connect GitHub-native collaboration with an authorized, independently verified AI delivery lifecycle. This shell does not certify a published product release.

## Product boundary

The product scope is public repositories owned by individuals or organizations, with multiple collaborators. Private repositories are Unsupported. Repository ownership, repository versus organization Runner registration, and optional Owner-enabled automatic registration are separate dimensions.

## Current status

Site implementation and local checks precede integrated browser verification and Pages deployment. Those integration outcomes remain Unverified and belong to #132. See [Quick Start](./quick-start/) for readiness boundaries and [Architecture](./architecture/) for responsibilities.
