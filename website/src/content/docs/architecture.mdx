## Repository responsibilities

Nibfin owns the sole Core, Skills and this website. nibfin-action is the Action entry; gh-nibfin is the onboarding CLI. The website is static information and performs no privileged operations, credential storage or Runner control.

## Planned lifecycle

Scope planning → approved raw Issue publication → Owner authorization → Shape → independent validation → Deliver → Candidate and isolated Hooks → independent Accept → exact-head CI → independent final review → protected Merge → required final proofs → Closure and receipt.

Native Blocked by relationships control dependencies. Scope publishing and read-only investigation are outside the protected delivery roles. GitHub owns Runner matching and queue behavior; Nibfin does not promise atomic cross-API routing or instant revocation.

## Verification ownership

This module owns local framework, governance, content, link and build checks. Integrated browser behavior and Pages deployment remain #132 obligations, currently Unverified.
